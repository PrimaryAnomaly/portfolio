## Context

Meeting notes apps usually ask for accounts, imports and configuration before they record anything. Hark has one button. Record, and the audio goes to a Cloudflare Worker, which makes a single Gemini call with native audio input and returns a transcript and structured notes as JSON. The Worker validates the shape of the response before the app displays it.

The Gemini API key lives only in the Worker, as a secret. It is never in the app or the repository.
